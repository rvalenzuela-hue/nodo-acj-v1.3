# Checklist de regresión — v0.8.34
## Plan de Prima / Beneficiarios por programa
- [x] Cada proyecto muestra un expediente desplegable `Beneficiarios del programa`.
- [x] Permite configurar los datos/columnas a solicitar.
- [x] Incluye campos base de colaborador, sucursal, beneficiario, parentesco, beneficio y valor estimado.
- [x] Captura individual mediante fila editable.
- [x] Descarga de plantilla Excel con las columnas configuradas.
- [x] Importación masiva XLS/XLSX/CSV.
- [x] Copiar y pegar bloques completos por filas y columnas directamente en la tabla.
- [x] Los datos pegados respetan exactamente el orden de columnas; no se adivinan columnas.
- [x] Formulario público generado y vinculado al proyecto/programa.
- [x] Posibilidad de retirar el formulario público.
- [x] Solicitudes del formulario aparecen en el registro consolidado.
- [x] Origen visible: captura, Excel o formulario público.
- [x] El ID de participante sólo se cruza con el colaborador/trabajador.
- [x] Beneficiarios, hijos, becados y familiares no reciben ID de participante.
- [x] Acciones individuales Imprimir y Eliminar.
- [x] Acciones masivas Editar, Imprimir y Eliminar.
- [x] Al clonar un programa se copia la estructura de campos, no los beneficiarios.
